# Memory Card Game

A fast-paced, interactive memory game built with **React** as part of [The Odin Project](https://www.theodinproject.com/) Frontend Development curriculum. The objective is to click on cards without selecting the same card twice. Every click shuffles the board!

## Features

- **Dynamic Data Fetching:** Cards are dynamically generated using an external API (e.g., Pokémon / Giphy / Rick & Morty API).
- **Randomized Shuffling:** Uses the Fisher-Yates shuffle algorithm to reorder the cards after every interaction.
- **Scoreboard Tracking:** Real-time tracking of your current score and all-time best score.
- **Game State Logic:** Detects win/loss conditions and resets seamlessly upon repeating a card.

## Built With

- **React** (Functional Components, Hooks: `useState`, `useEffect`)
- **JavaScript (ES6+)**
- **CSS3** (Flexbox / Grid)
- **Vite** (Build Tool)
